# Medicaid example

`references.csv` and `answers.csv` reproduce the Medicaid instance of the GT-FENG paper (Section 5, Table 3). Build them from the supplementary materials of Feng (2026), "Right Number, Wrong State?", with `build_tables.py`, then run `run_example.py`.

Data license: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Gold values are derived from MACPAC MACStats Exhibits 35–36, 2018–2025. Model answers are from Claude Sonnet 5.5 and GPT-5.6 Sol.
